This policy covers the Aperture Archive GitHub Pages website. It does not replace the separate policies of GitHub or image hosts.

ABOUT THE PROJECT ↗

1. Who operates this website

Aperture Archive is an independent, unofficial Portal 2 preservation community website. The website is a static site hosted through GitHub Pages. The website is maintained by @ScallywagDude on GitHub. For privacy inquiries, use the public contact options on the maintainer’s GitHub profile or the project repository.

2. Information collected by the website

This website does not have accounts, contact forms, advertising, analytics, tracking pixels, or first-party cookies. Search and filtering of the archive run in your browser; queries are not sent to our server by the site code. We do not intentionally collect names, email addresses, or other personal data through these pages.

3. GitHub Pages hosting

GitHub hosts the static site and may process technical data such as IP addresses, browser information, and access logs under GitHub's own privacy practices. See GitHub's Privacy Statement ↗.

4. Community discussions

Our forum links use GitHub Discussions. If you participate, GitHub may handle your account, username, posts, reactions, and other activity according to its own terms and privacy policy. Discussions you make public may be visible to others, including search engines. The forum is not hosted directly on this website.

5. Historical images and third-party content

Historical development images load from credited external sources, including Valve Archive and other publications. Opening pages that contain these images may cause your browser to connect to those hosts, which may receive information such as your IP address. You can disable remote images in your browser. Image hosts have their own privacy policies.

6. External links

Links to sources, discussions, and any future downloads open third-party websites. We do not control those services or their data practices. Review their policies before using them.

7. Changes to this policy

We will update this page if the site introduces new features, services, or data collection. We will update the effective date when material changes are published.

8. Contact, removal, and corrections

To request a correction or report a privacy concern, contact @ScallywagDude or open a discussion on the project repository.
